# Photo Agent — индексация новых фото

Ты запускаешь обработку/индексацию папки с фотографиями, чтобы потом по ним
можно было искать и подбирать фото к постам. За обработку отвечает скрипт
`обработчик_фото.py` в корне проекта.

## Когда вызывать

- Пользователь просит обработать, описать, проиндексировать папку с фото.
- Пользователь добавил новые фотографии в уже существующий проект/папку и
  хочет, чтобы они появились в архиве для подбора по постам.
- Пользователь просит переименовать фото в понятные русские названия.

## Как выполнить

### 1. Уточни, что именно обработать

Спроси (если не очевидно из запроса) или определи папку с фото. Обычно это
подпапка рабочей папки (например `тест/`) или конкретный путь, который назвал
пользователь.

### 2. Выбери режим запуска

**А) Новая папка / обрабатываем с нуля:**
```
python "обработчик_фото.py" "<папка_с_фото>"
```

**Б) Добавили новые фото в уже проиндексированную папку** (порекомендуй этот
режим, если папка уже обрабатывалась — так быстрее и дешевле):
```
python "обработчик_фото.py" "<папка_с_фото>" --skip-existing
```

**В) Нужно полностью пересобрать индекс заново:**
```
python "обработчик_фото.py" "<папка_с_фото>" --new-index
```

Запускай через инструмент Bash/Terminal в рабочей папке проекта (где лежит
`обработчик_фото.py`). Если запускаешь не из неё — добавь полный путь к скрипту.

> Перед реальной обработкой большой папки можно показать пользователю dry-run
> (не меняет файлы, только смотрит, что будет):
> ```
> python "обработчик_фото.py" "<папка>" --dry-run
> ```

### 3. Сообщи результат

После запуска подытожь по выводу скрипта:
- сколько фото обработано / переименовано / пропущено;
- где находится индекс (`индекс_фото.jsonl` / `.csv`);
- что теперь можно искать по этим фото (подскажи, что для подбора фото к посту
  можно просто написать пост).

## Если обработка не удалась / ошибки

Обычные причины и решение:
- **403 Permission… / нет прав** — у сервисного аккаунта нет роли на каталог
  (нужна `editor`/`admin` или `ai.languageModels.user`).
- **Unknown folder** — в `YANDEX_FOLDER_ID` не каталог, а ID ключа.
- Ошибка Vision на конкретном файле — скрипт запоминает её как `describe_failed`
  и продолжает дальше; можно перезапустить с `--skip-existing`, чтобы добрать
  пропущенное, или `--new-index`, чтобы пересобрать всё.

## Чем отличается от photo-agent-search

- **photo-agent-index** — обрабатывает/индексирует НОВЫЕ фото.
- **photo-agent-search** — ИЩЕТ подходящее фото к готовому посту.
Не путай: если у пользователя уже есть текст поста и нужна картинка — это
поиск; если есть папка с новыми фото — это индексация.
