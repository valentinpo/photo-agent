# Photo Agent — подбор фото к посту

Ты помогаешь выбрать фотографию(и) для поста в мессенджер из уже
проиндексированного архива. Поиск ведётся по тексту поста через скрипт
`поиск_фото.py`, который живёт в корне этого проекта.

## Когда вызывать

- Пользователь даёт текст поста и просит подобрать к нему фото/изображение.
- Или называет тему/настроение («уютная веранда», «зимний лес», «баня на снегу»)
  и спрашивает, есть ли подходящее фото в архиве.

## Как выполнить

### 1. Определи папку с индексом

Скрипт ищет в папке файл индекса `индекс_фото.jsonl`. Обычно это подпапка
проекта с фото (например `тест/`). Если пользователь уточнил проект/папку —
используй её. Если не уточнил — проверь, какие подпапки содержат `индекс_фото.jsonl`
(например через `glob` `**/индекс_фото.jsonl`) и выбери подходящую(ие).

### 2. Запусти поиск

Рабочая папка проекта — та, где лежит `поиск_фото.py` (если запускаешь не из неё,
сначала найди её через `glob` `**/поиск_фото.py` и добавь путь к скрипту). Выполни:

```
python "поиск_фото.py" "<текст поста>" "<папка_с_индексом>"
```

Пример:
```
python "поиск_фото.py" "уютная деревянная веранда с гирляндами для поста про осень" "тест"
```

Можно перечислить несколько папок через пробел:
```
python "поиск_фото.py" "<пост>" "папка1" "папка2"
```

Опции (по необходимости):
- `-n 3` — вывести только 3 лучших результата.
- `--json` — получить машиночитаемый вывод (если результат нужен для дальнейшей
  обработки, например открытия файла).

Запускай через инструмент Bash/Terminal в рабочей папке проекта.

### 3. Верни результат пользователю

Выведи 1–3 лучших найденных фото. Для каждого укажи:
- **Путь к файлу** (абсолютный) — чтобы пользователь/агент мог его открыть.
- **Почему выбран** — короткое объяснение на основе вывода скрипта
  (совпадение по ключевым словам / заголовку / описанию).

Не выдумывай причины — бери их из вывода `поиск_фото.py` (блок «Почему:»).

## Формат ответа (пример)

```
По запросу «уютная веранда с гирляндами» лучше всего подходят:

1. C:\...\фото\уютная_деревянная_терраса_ночью.jpg
   — потому что в описании «деревянная терраса», подходит по настроению «уютная»,
     и в ключевых словах есть «гирлянда».

2. C:\...\фото\ночная_деревянная_баня_в_снегу.jpg
   — совпадает по слову «деревянная», зимняя/уютная атмосфера.
```

## Если ничего не нашлось

Скажи пользователю, что в текущем индексе нет подходящих фото, и предложи:
- изменить формулировку запроса (другие слова/синонимы);
- добавить индекс/папку (уточни у пользователя путь);
- обработать новую папку фото через `обработчик_фото.py` и попробовать снова.

## Если добавили новые фото в уже проиндексированную папку

Чтобы обновить индекс без повторов старых описаний, запусти:
```
python "обработчик_фото.py" "<папка_с_фото>" --skip-existing
```
Это опишет только новые файлы (уже проиндексированные будут пропущены),
переименует сырые имена и обновит `индекс_фото.jsonl`/`.csv`. Затем повтори поиск.
